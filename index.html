Featured Project · AI Automation · CBRE
Intelligent Document Extractor & Auto-Property Creator

CBRE brokers were spending significant time manually reading through high volumes of requirement emails — each containing attachments, inline data, and mixed intent — before manually creating Property, Availability, Lease, or Requirement records in the platform. We eliminated that entirely.

The system reads each inbound email (body + attachments — PDFs, Word docs, Excel sheets), classifies the intent (new requirement, confirmation, query, or clarification request), extracts all structured fields, and either auto-creates the relevant record or routes it to the right workflow. Brokers now open their inbox to find records already created and waiting — not raw emails to parse.

GoLang NLP / LLM Document Parsing Email Automation AWS Real Estate APIs
How It Works
1
Email Ingestion — Broker inbox monitored; email body & all attachments (PDF, DOCX, XLSX) captured in real time
2
Intent Classification — Each email classified: New Requirement · Confirmation · Client Query · Clarification Request
3
Data Extraction — Property details, lease terms, availability windows, client data extracted from unstructured text & documents
4
Auto Record Creation — Property, Availability, Lease, or Requirement record auto-created in MarketIQ — or routed to clarification workflow if data is incomplete
5
Broker Review — Record ready for broker validation; no manual data entry required
